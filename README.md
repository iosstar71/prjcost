# PM Hub Cost — 프로젝트 원가 관리 (v0.9)

착수 전 프로젝트의 인건비 · 경비 · 분할계약 · 견적을 넣고 원가와 이익률을 바로 계산합니다.
**설치도 서버도 필요 없습니다.** 엑셀 파일을 DB 처럼 써서, 고른 폴더에 프로젝트마다 엑셀 파일 하나로 저장합니다.

## 쓰는 법
1. 압축을 풀고 `index.html` 을 **크롬 또는 엣지**로 엽니다 (더블클릭).
2. **[📁 폴더 연결]** 로 자료 폴더를 고릅니다.
   - 처음이면 압축을 푼 폴더(또는 그 안의 `data`)를 고르면 됩니다.
   - 예전 버전(v4, 파이썬)을 쓰셨다면 그 프로그램 폴더나 `data` 폴더를 고르세요. 프로젝트를 그대로 씁니다.
3. 다음부터는 브라우저가 폴더를 기억합니다. 다시 열면 **[폴더 다시 연결]** 을 한 번 누릅니다. 브라우저 보안 규칙이라 이 한 번은 꼭 눌러야 합니다.
4. 입력하면 바로 다시 계산됩니다. **[💾 저장] 또는 Ctrl+S** 를 눌러야 파일에 기록됩니다.
   - 저장하지 않은 변경이 있으면 "● 저장 안 됨"이 보이고, 다른 프로젝트로 갈 때 먼저 묻습니다.

## 자료 폴더
| 위치 | 내용 |
|---|---|
| `master/master_rates.xlsx` | 기준정보 (등급 단가 · 외주 단가 · 인비례율 · 경비 계정) — 새 프로젝트의 기본값 |
| `projects/<프로젝트ID>.xlsx` | 프로젝트 하나에 파일 하나. Excel 로 열어 보면 정보 · 인력 · 경비 · 분할계약 · 견적 · 저장 이력 시트가 있음 |
| `backups/` | 저장할 때마다 바로 전 파일 (프로젝트마다 최근 20개) |
| `backups/deleted/` | 지운 프로젝트 — `projects` 로 다시 옮기면 되살아남 |
| `templates/project_upload_template.xlsx` | 기본 정보만 적어 [⬆ 엑셀 열기]로 여는 양식 |

- 프로젝트 파일을 Excel 로 열어 둔 채 저장하면, 저장하기 전에 알려 줍니다. 다른 곳에서 먼저 바뀐 파일은 그냥 덮어쓰지 않습니다.
- 숨은 시트 `State_JSON` 이 다시 불러올 때 쓰는 원본 자료입니다. 이 시트는 고치지 마세요.

## 크롬 · 엣지가 아닌 브라우저
폴더 저장을 지원하지 않습니다. 그 경우 [저장]을 누르면 엑셀 파일을 내려받고, [⬆ 엑셀 열기]로 다시 엽니다.

## 개발
- 시험: `node tests/run.js` (계산 · 엑셀 단위 시험, 1초) · `node tests/e2e.js` (화면 시험, 약 20초, Playwright)
- 배포 zip: `python tools/make_release.py <출력 폴더>`
- 규칙: `CLAUDE.md`, 자료 정의: `docs/DATA_MODEL.md`, 변경 이력: `RELEASE_NOTES.md`
