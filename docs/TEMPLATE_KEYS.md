# 보고서 양식 (템플릿)

회사 보고서 양식(엑셀)에 이 프로그램의 값을 채워 새 파일로 만든다. 머리줄 **[사업검토서]**.

## 양식 파일
- 자료 폴더의 `templates/` 에 있는 `.xlsx` 가 목록에 나온다 (`project_upload_template.xlsx` 는 프로젝트 올리기용이라 빠짐).
- 기본 양식 `Offline사업검토서_단가고정.xlsx` · `Offline사업검토서_단가변경.xlsx` 는 폴더를 연결할 때 없으면 넣어 준다. 이미 있으면(고친 양식) 건드리지 않는다. 예전 이름 `Offline사업검토서.xlsx` 도 폴더에 있으면 그대로 목록에 나온다.
- 양식은 Excel 에서 직접 고친다. 값이 들어갈 칸에 `{{이름}}` 을 적는다.
  - 칸에 자리표시 **하나만** 있으면 값을 그대로 넣는다. 숫자는 숫자로 들어가 칸의 서식(통화 `"₩"#,##0`, 백분율 `0.00%`)이 적용된다. 비율은 `0.4667` 같은 소수 → `0.00%` 서식이면 46.67%.
  - 글과 **섞여** 있으면(`{{시작일}} ~ {{종료일}} ({{개월수}}개월)`) 글자로 바꿔 넣는다. 숫자는 `1,234` 꼴.
  - 값이 없으면 빈칸. 모르는 이름(오타)은 빈칸으로 두고 출력 뒤에 알려 준다.
- 칸의 꾸밈 · 병합 · 열 너비 · 행 높이 · 인쇄 설정은 그대로. 파일을 열 때 Excel 이 수식을 다시 계산한다.
- 출력 파일: `<양식 이름>_<프로젝트ID>_<프로젝트명>_<최종작성일 YYYYMMDD>.xlsx` — 내려받고, 폴더가 연결돼 있으면 `reports/` 에도 남김. 최종작성일 = 프로젝트를 마지막으로 저장한 날(저장 안 한 변경이 있으면 오늘).
- **반복 줄**: 칸에 `{{내부인력.성명}}` 처럼 **목록 이름.값 이름**이 있는 줄은 목록의 항목 수만큼 복사해서 채웁니다 (목록이 비면 빈 줄 하나). 아래 줄 · 병합 · 인쇄 영역은 늘어난 만큼 밀립니다. 반복 줄 안의 병합(한 줄 안)은 줄마다 복사되고, 여러 줄 병합의 끝이 반복 줄이면 늘어난 줄까지 넓어집니다 (예: 5Tier B5:B6 → 마지막 인력 줄까지).
  - 반복 줄이 늘면 **수식의 칸 참조도 맞춰 옮깁니다** (아래 「수식」).
- **묶음 값**: `{{내부합계.총MM}}` 처럼 묶음 이름.값 이름.
- 기간 밖의 달 열: 머리글 칸이 `{{월N}}` 이고 그 달이 기간 밖이면 출력할 때 그 열을 숨깁니다.
- 달은 첫 달부터 M1 … M12 (1년까지). 기간 밖의 달은 빈칸이고, 기간이 12개월을 넘으면 `{{기간초과}}` 에 안내 글.

## 수식 (합계를 수식으로 — 출력 파일을 고치면 합계가 따라 바뀜)
- 합계 칸에는 자리표시 대신 Excel 수식을 넣어도 됩니다. 출력할 때 반복 줄에 맞춰 칸 참조를 옮깁니다 (`js/formula.js`).
  - 범위의 끝이 반복 줄이면 늘어난 줄까지: `=SUM(O5:O6)` → 내부 인력 3명이면 `=SUM(O5:O8)`
  - 반복 줄 아래 칸은 늘어난 만큼 내림. 다른 시트에서 가리키는 것도: `=원가상세!O7` → `=원가상세!O9`
  - 반복 줄 안의 수식은 줄마다 그 줄로: 5Tier `=SUM(H5:S5)` → 다음 사람 줄은 `=SUM(H6:S6)`
  - Excel 이 끌어 채운 공유 수식도 칸마다 풀어서 옮김
- 수식 칸에는 계산한 값도 넣습니다 (다시 계산하지 않는 미리보기 · 휴대폰에서도 숫자가 보이게). 계산하는 함수: SUM · COUNT · COUNTA · COUNTIF · SUMIF · IF · IFERROR · ROUND(UP/DOWN) · INT · ABS · MIN · MAX · AVERAGE · AND · OR · NOT, 사칙연산 · & · 비교. 다른 함수는 Excel 에서 계산되고, 출력 뒤에 "계산해 보지 못한 수식"으로 알림
- 기본 양식의 수식 칸
  | 시트 | 칸 |
  |---|---|
  | 원가상세 | 소계 인원수 `COUNTIF(투입공수,">0")` · 투입공수 · 투입원가 `SUM`(내부 소계는 OT비용 줄 포함), 전체 = 내부 + 외주, 재료비 합계 · 경비 합계 `SUM` |
  | 사업개요 Ⅱ | 노무비 · 외주비 · 재료비 = 원가상세 소계, AI예비비 = 원가상세 경비 중 계정이 `AI예비비` 인 금액(`SUMIF`), 경비 = 경비 합계 − AI예비비, 합계 `SUM`, 백분율 = 금액 ÷ 합계 |
  | 사업개요 Ⅲ | 매출액 = 사업개요 매출액, 원가 = 사업원가 합계, 매출마진 = 매출액 − 원가, 수주마진율 = 매출마진 ÷ 매출액, Gap = 수주마진율 − H/R |
  | 5Tier | 사람별 MM합계 = 그 줄 달별 MM 합, 합계 줄 = 열마다 합 |
- 사람별 투입원가 · 단가는 값입니다 (달마다 인상 단가가 다를 수 있어 `MM × 단가` 로 계산하면 금액이 달라짐). 출력 파일에서 사람 금액 · MM 을 고치면 위 합계가 모두 따라 바뀝니다.

## 검증 (출력할 때마다)
- 숨긴 시트 **「검증」**: 줄마다 A 항목 · B 양식 수식(`=사업개요!D19`) · C 프로그램 값(`{{총원가}}`) · D 차이. 출력할 때 B 를 계산해 C 와 같은지 봅니다 (빈칸 = 0, 비율은 소수 끝자리 차이 무시).
- 모두 같으면 알림에 "합계 수식 검증 40개 항목 일치". 다르면 항목 · 양식 값 · 프로그램 값을 창으로 알림 (파일은 만들어짐) — 양식의 합계 범위 · 참조를 고칠 때 확인용
- 양식을 고쳐 합계 칸 위치가 바뀌면 「검증」 시트의 B열 참조도 맞춰 주세요 (Excel 에서 [숨기기 취소]). 「검증」 시트가 없는 양식은 검증하지 않습니다.
- 개발 시험: `node tests/excel_recalc.js` — 여러 모양의 프로젝트(여러 명 · 인상 · OT · 재료비 · 부서 2개 · 0명 · 15개월)로 출력한 파일을 LibreOffice 로 다시 계산해, 모든 수식 칸이 이 프로그램의 계산과 같고 「검증」이 맞는지 봄 (약 5초)

## 자리표시 (js/template.js 의 KEYS 와 같게)
| 이름 | 값 |
|---|---|
| 프로젝트ID · 과제명 · 과제내용 · 고객사 · PM · 영업대표 | 프로젝트 개요 (과제명 = 프로젝트명, 과제내용 = 프로젝트 설명) |
| 프로젝트Type | 프로젝트 개요의 프로젝트 Type |
| 결재1 ~ 결재5 | 기준정보 > 기본값의 결재자 (기안(PM) · 검토 · 사업팀장 · 영업팀장 · 본부장) |
| 매출액 | 계약 매출 |
| 시작일 · 종료일 · 개월수 | 기간 (YYYY.MM.DD, 월 단위면 1일 · 말일) |
| 귀속부서 | 첫 부서 (부서가 없으면 빈칸) |
| 노무비 · 외주비 · 경비 · AI예비비 · 총원가 | 내부 인건비 · 외주 인건비 · 일반 + 인비례 + 기타경비(AI예비비 제외) · 경비 중 이름이 AI예비비 · 총 원가 |
| 노무비율 · 외주비율 · 경비율 · AI예비비율 · 총원가율 | 위 금액 ÷ 총 원가 (소수) |
| 매출마진 · 수주마진율 · 허들 · Gap | 매출 − 총 원가 · 매출마진 ÷ 매출 · 목표 허들 이익률 · 수주마진율 − 허들 (비율은 소수) |
| 최근버전이름 · 최근버전매출 · 최근버전마진율 | 가장 최근 저장한 [버전] (사업검토서의 수주협 4차) |
| 견적합계 · 견적할인율 · 견적할인액 · 견적절사액 · 견적공급가 | 견적 합계(할인 전) · 할인율(소수) · 할인 금액 · 절사 금액 · 견적 금액(할인 · 절사 후) |
| 작성일 · 최종작성일 | 출력한 날 · 마지막 저장한 날 (YYYY.MM.DD) |

## 최초 · 변경 단가 (`_단가변경` 양식)
- 최초단가 = 그 사람이 투입된 첫 달의 단가, 변경단가 · 변경월 = 그 뒤 처음 달라진 단가와 달 (연봉 인상 · 협상 단가 — 기준정보에 등록한 것만), MM최초 · MM변경 = 단가별 MM 합 (기간 전체)
- 바뀌지 않으면 변경단가 · 변경월 · MM변경은 빈칸, MM최초 = 총MM. 1년에 두 번 바뀌면 첫 변경만 표시 (금액은 달별 단가대로)

## 배포 전에 기본 양식 바꾸기 (관리자용, 화면에서)
1. 고친 양식(xlsx)을 연결한 자료 폴더의 `templates/` 에 넣음 (같은 이름이면 기본 양식을 바꾸고, 새 이름이면 더해짐)
2. [기준정보 > 프로젝트 설정 > 보고서 양식 · 샘플] → **[배포용 기본 양식 만들기]** → `builtin-templates.js` 내려받기
3. 프로그램 폴더의 `js/builtin-templates.js` 를 이 파일로 바꾼 뒤 압축해 배포
- 폴더를 연결하기 전에는 프로그램 안에 담긴 기본 양식(`js/builtin-templates.js`)으로 출력하므로 `data/templates` 의 엑셀만 고쳐서는 바뀌지 않음

## 기본 양식 고치기 (개발)
`data/templates/Offline사업검토서.xlsx` 를 Excel 로 고친 뒤 `python3 tools/make_templates.py` → `js/builtin-templates.js`(같은 파일 base64). 그다음 `node tests/run.js` · `node tests/excel_recalc.js`.
