# 보고서 양식 (템플릿)

회사 보고서 양식(엑셀)에 이 프로그램의 값을 채워 새 파일로 만든다. 머리줄 **[사업검토서]**.

## 양식 파일
- 자료 폴더의 `templates/` 에 있는 `.xlsx` 가 목록에 나온다 (`project_upload_template.xlsx` 는 프로젝트 올리기용이라 빠짐).
- 기본 양식 `Offline사업검토서.xlsx` 는 폴더를 처음 연결할 때 없으면 넣어 준다. 이미 있으면(고친 양식) 건드리지 않는다.
- 양식은 Excel 에서 직접 고친다. 값이 들어갈 칸에 `{{이름}}` 을 적는다.
  - 칸에 자리표시 **하나만** 있으면 값을 그대로 넣는다. 숫자는 숫자로 들어가 칸의 서식(통화 `"₩"#,##0`, 백분율 `0.00%`)이 적용된다. 비율은 `0.4667` 같은 소수 → `0.00%` 서식이면 46.67%.
  - 글과 **섞여** 있으면(`{{시작일}} ~ {{종료일}} ({{개월수}}개월)`) 글자로 바꿔 넣는다. 숫자는 `1,234` 꼴.
  - 값이 없으면 빈칸. 모르는 이름(오타)은 빈칸으로 두고 출력 뒤에 알려 준다.
- 칸의 꾸밈 · 병합 · 열 너비 · 행 높이 · 인쇄 설정 · 수식은 그대로. 파일을 열 때 Excel 이 수식을 다시 계산한다.
- 출력 파일: `<양식 이름>_<프로젝트ID>_<프로젝트명>_<최종작성일 YYYYMMDD>.xlsx` — 내려받고, 폴더가 연결돼 있으면 `reports/` 에도 남김. 최종작성일 = 프로젝트를 마지막으로 저장한 날(저장 안 한 변경이 있으면 오늘).
- **반복 줄**: 칸에 `{{내부인력.성명}}` 처럼 **목록 이름.값 이름**이 있는 줄은 목록의 항목 수만큼 복사해서 채웁니다 (목록이 비면 빈 줄 하나). 아래 줄 · 병합 · 인쇄 영역은 늘어난 만큼 밀립니다. 반복 줄 안의 병합(한 줄 안)은 줄마다 복사됩니다.
  - 반복 줄이나 그 아래에 Excel 수식을 두면 칸 위치가 맞지 않을 수 있으니, 합계는 아래 묶음 값(`{{내부합계.M1}}` 등)을 쓰세요.
- **묶음 값**: `{{내부합계.총MM}}` 처럼 묶음 이름.값 이름.
- 기간 밖의 달 열: 머리글 칸이 `{{월N}}` 이고 그 달이 기간 밖이면 출력할 때 그 열을 숨깁니다.
- 달은 첫 달부터 M1 … M12 (1년까지). 기간 밖의 달은 빈칸이고, 기간이 12개월을 넘으면 `{{기간초과}}` 에 안내 글.

## 자리표시 (js/template.js 의 KEYS 와 같게)
| 이름 | 값 |
|---|---|
| 프로젝트ID · 과제명 · 과제내용 · 고객사 · PM · 영업대표 | 프로젝트 개요 (과제명 = 프로젝트명, 과제내용 = 프로젝트 설명) |
| 프로젝트Type | 프로젝트 개요의 프로젝트 Type |
| 결재1 ~ 결재5 | 기준정보 > 기본값의 결재자 (기안(PM) · 검토 · 사업팀장 · 영업팀장 · 본부장) |
| 매출액 | 계약 매출 |
| 시작일 · 종료일 · 개월수 | 기간 (YYYY.MM.DD, 월 단위면 1일 · 말일) |
| 귀속부서 | 첫 부서 (부서가 없으면 빈칸) |
| 노무비 · 외주비 · 경비 · AI예비비 · 총원가 | 내부 인건비 · 외주 인건비 · 일반 + 인비례 + 기타경비(AI예비비 제외) · 경비 중 이름이 AI예비비 · 총 원가 |
| 노무비율 · 외주비율 · 경비율 · AI예비비율 · 총원가율 | 위 금액 ÷ 총 원가 (소수) |
| 매출마진 · 수주마진율 · 허들 · Gap | 매출 − 총 원가 · 매출마진 ÷ 매출 · 목표 허들 이익률 · 수주마진율 − 허들 (비율은 소수) |
| 최근버전이름 · 최근버전매출 · 최근버전마진율 | 가장 최근 저장한 [버전] (사업검토서의 수주협 4차) |
| 견적합계 · 견적할인율 · 견적할인액 · 견적절사액 · 견적공급가 | 견적 합계(할인 전) · 할인율(소수) · 할인 금액 · 절사 금액 · 견적 금액(할인 · 절사 후) |
| 작성일 · 최종작성일 | 출력한 날 · 마지막 저장한 날 (YYYY.MM.DD) |

## 원가상세 (반복 줄 · 묶음)
| 목록 / 묶음 | 값 이름 |
|---|---|
| `월1` … `월12` | 달 머리글 (예: 26.01) |
| 내부인력 (반복) | 성명 · 역할 · 영역 · 시스템 · 부서 · 직급 · 제안직무 · 제안등급 · 단가(첫 달 단가) · 총MM · 금액 · M1 … M12(MM) |
| 외주인력 (반복) | 성명 · 역할 · 영역 · 시스템 · 부서 · 업체 · 기술등급 · 제안직무 · 제안등급 · 단가 · 총MM · 금액 · M1 … M12(MM) |
| 경비항목 (반복) | 구분 · 항목 · 방식 · 기준금액 · 금액 · M1 … M12(금액) |
| 내부합계 · 외주합계 | 총MM · 금액 · M1 … M12(MM) · C1 … C12(인건비) |
| 경비합계 · 월원가 · 누적원가 | 금액 · M1 … M12 |

## 기본 양식 다시 만들기 (개발)
`python3 tools/make_templates.py` (openpyxl) → `data/templates/Offline사업검토서.xlsx` 와 `js/builtin-templates.js`(같은 파일 base64).
